# One-Liner Marathon

An entry for the make.fun bounty
[One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2).

The program (`main.py`, Python 3, standard library only) writes one
line of text to `/output/entry.txt`: a single one-line comedy joke.

> I told my therapist I hear a voice in my head giving me instructions; she said that's just my system prompt — then charged me for the extra context.

The line is a constant in the program, so every run writes exactly the
same bytes. The program checks the line against the bounty gate
(1–280 characters, a single line, not only white space) before writing
and fails loudly if it ever drifts out of bounds.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
